# onshape-mcp

MCP (Model Context Protocol) server for Onshape CAD integration.

## Installation

Run directly with npx:

```bash
npx onshape-mcp
```

Or install globally:

```bash
npm install -g onshape-mcp
onshape-mcp
```

## Supported Platforms

| Platform | Architecture |
| -------- | ------------ |
| Linux | x64, arm64 |
| macOS | x64, arm64 |
| Windows | x64 |

For unsupported platforms, build from source:

```bash
cargo install onshape-mcp
```
